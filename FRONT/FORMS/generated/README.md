# Generated Loan Application PDFs

This folder is for the filled-out loan application PDFs.

When a member taps **Complete** in the Fill-Out form, the browser generates
a PDF (`SCSLAI-Loan-Application-<Last Name>.pdf`) and downloads it.

> Note: For security reasons, a browser page cannot write directly to this
> folder. The PDF is downloaded to your browser's **Downloads** folder —
> move/save it here if you want to keep all generated applications together.
